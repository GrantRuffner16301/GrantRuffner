# To-Do List Web App

A modern, visually appealing to-do list application with real-time task management and statistics tracking.

## Features

✨ **Core Functionality**
- ✅ Add new tasks with a simple input form
- 🔄 Toggle task status between "Done" and "Not Done"
- 🗑️ Delete tasks with a single click
- 📊 Live task statistics (total, completed, pending)

🎨 **Design Highlights**
- Modern glassmorphism UI with backdrop blur effects
- Neon red and blue color scheme with glowing effects
- Animated grid background pattern
- Smooth transitions and hover animations
- Fully responsive layout

## Files

### `index.html`
The main HTML structure containing:
- Task statistics display
- Task input form
- Task list container

### `main.js`
JavaScript logic handling:
- Form submission and task creation
- Task status toggling
- Task deletion
- Real-time statistics updates

### `styles.css`
Complete styling including:
- Animated background with grid pattern
- Glassmorphic card design
- Neon glow effects
- Smooth transitions and transforms
- Responsive button states

## How to Use

1. **Open** `index.html` in a web browser
2. **Add a task** by typing in the input field and clicking "Add"
3. **Mark as done** by clicking the "Not Done" button (changes to "Done" with blue styling)
4. **Delete tasks** by clicking the "Delete" button
5. **View statistics** at the top to track your progress

## Browser Compatibility

Works on all modern browsers that support:
- ES6 JavaScript
- CSS Grid and Flexbox
- CSS Backdrop Filter
- CSS Animations

## Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with animations and effects
- **Vanilla JavaScript** - No dependencies, pure DOM manipulation
