# Grant's Awesome WebSite

A stylish, modern first web page with a sleek dark theme and animated grid background.

## Overview

This project showcases a clean, responsive webpage design featuring:
- **Dark theme** with neon blue and red accents
- **Animated grid background** for visual depth
- **Gradient headers and footers** with glowing text effects
- **Smooth navigation** with hover effects
- **Responsive layout** centered content with shadow effects

## Features

✨ **Modern Design**
- Dark background (`#0a0f1f`) with subtle animated grid pattern
- Blue and red neon color scheme with glowing text shadows
- Gradient backgrounds on header and footer elements

🎨 **Visual Effects**
- Animated grid background that continuously moves
- Radial gradient overlay for depth
- Hover effects on navigation links
- Box shadows and text shadows for visual enhancement

📱 **Layout**
- Semantic HTML structure
- Centered main content with max-width constraint
- Flexible navigation menu
- Footer with copyright information

## Files

- `index.html` - Complete HTML page with embedded CSS styling

## Structure

The page includes three main sections:
1. **Home** - Welcome introduction
2. **Projects** - Showcase area for projects
3. **Contact** - Contact information section

## Colors Used

- **Background**: `#0a0f1f` (dark navy)
- **Primary Accent**: `#0066ff` (bright blue)
- **Secondary Accent**: `#ff0033` (bright red/pink)
- **Text**: `#e0e0e0` (light gray)
- **Grid**: `#1220df` (blue grid lines)

## How to Use

1. Open `index.html` in a web browser
2. Navigate between sections using the menu links
3. Customize the content in each section as needed

## Customization

You can easily customize this page by:
- Modifying the color variables in the `<style>` section
- Updating content in each section
- Adjusting the grid size by changing the `background-size` and animation duration
- Adding more navigation links and sections
