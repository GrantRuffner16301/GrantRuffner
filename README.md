## Featured Projects

### 🚀 [Asteroids: Ship PowerUps Edition](Asteroid_JavaScript/index.html)
A dependency-free vanilla JavaScript arcade shooter built with the HTML5 Canvas API.

- Momentum-based movement, particle effects, collision detection, and screen wrapping
- Weapon power-ups including Spread, Double, Pierce, and Ricochet fire
- Multi-channel Web Audio effects and persistent browser-based high scores
- **[Play the live demo](https://grantruffner16301.github.io/GrantRuffner/Asteroid_JavaScript/)**

**Technologies:** JavaScript, HTML5 Canvas, Web Audio API, Local Storage

### 🕒 [Modern Analog Clock for macOS](modern_analog_clock/modern_clock2.py)
A lightweight PyQt6 desktop clock designed for the MacBook Air M4 aesthetic.

- Frameless, always-on-top interface with adjustable opacity
- Custom themes including Midnight Blue, Stealth Gray, and Mahogany Wood
- Optional minute marks and adaptive text contrast

**Technologies:** Python, PyQt6

### 🎨 [Grant's Primary Color Mixing Lab](Paint_Color_Mixer/paint_color_mixer.py)
An interactive color-mixing application that models subtractive paint blending using Red, Yellow, and Blue (RYB) logic.

- Converts custom pigment mixtures into digital RGB colors
- Saves and loads a user-managed pigment library with JSON
- Includes scrollable controls, double-click clearing, and Shift-to-Subtract behavior

**Technologies:** Python, Pygame, JSON

### 📚 [Amber's Home Library System](Ambers_Library_System/Ambers_Library_System.py)
An end-to-end lending library application for managing books, members, loans, and QR-based checkout workflows.

- SQLite database with foreign keys for books, members, and active loans
- Real-time QR/barcode scanning with OpenCV
- UUID-based tracking, JSON persistence, PDF generation, and a dedicated scan station

**Technologies:** Python, SQLite, OpenCV, QRCodeDetector, JSON, PDF generation

### 🚲 [Arduino Smart Bike Tail Light System](Bike_tail_lights/Bike_Tail_Lights.ino)
A feature-rich bicycle lighting system using WS2812B LEDs and an I2C OLED status display.

- Bright brake indication using normally closed brake-button logic
- Sequential amber turn signals and optional low-intensity tail lighting
- OLED status display for left, right, hazard, brake, and tail-light modes

**Hardware:** Arduino Uno/Nano/Pro Mini, WS2812B LEDs, SSD1306 OLED, switches  
**Libraries:** FastLED, Adafruit GFX, Adafruit SSD1306
